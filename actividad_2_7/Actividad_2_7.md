Ejercicio 1: Variable inexistente:

Enunciado:

-Este script debería mostrar la suma de a y b, pero algo no funciona.

-Usa un breakpoint en la línea del console.log.
-Inspecciona las variables activas y averigua qué causa el error.
-Corrige el código para que muestre correctamente el resultado.

-En este ejeercisio realmente no hace falta usar un breakpoint, y las variables estan bien, en este caso el error es un error sintactico ya que el metodo "result" al llamarlo en el console.log se le llama como "reslt" y este no existe. Para solucionarlo habria que cambiar en console.log la llamada del metodo "reslt" a "result".
